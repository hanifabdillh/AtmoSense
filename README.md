# AtmoSense

**AtmoSense** is an IoT-based mobile application developed for real-time urban air quality monitoring and PM2.5 prediction. The application integrates environmental sensor data, Firebase Realtime Database, Edge Computing, and a Random Forest Regressor running on a Raspberry Pi 4.

This project was developed as part of the **Capstone Design – Telecommunication Engineering, Faculty of Electrical Engineering, Telkom University**.

---

## Overview

Air quality conditions can change dynamically, especially in urban environments with high transportation and human activity. AtmoSense was developed to provide users with real-time environmental information while also presenting PM2.5 prediction results generated through machine learning.

The system uses an **ESP32** as the sensor acquisition node, **Firebase Realtime Database** for data synchronization and storage, and a **Raspberry Pi 4** as the Edge Computing device for local machine learning inference.

The predicted PM2.5 value is then converted into an **ISPU category** and displayed through the AtmoSense mobile application.

---

## Key Features

### Real-Time Dashboard
Displays real-time air quality information, including:

- ISPU value
- Air quality category
- PM1.0
- PM2.5
- PM10
- CO from MQ-7
- Multi-gas reading from MQ-135
- Temperature
- Humidity
- Sensor connectivity status

### Location Monitoring
Provides location-based monitoring through a digital map, including:

- Monitoring station location
- Location name
- Device status
- Latitude and longitude
- Current ISPU value

### PM2.5 Prediction
Displays machine learning prediction results generated by the **Random Forest Regressor** running on the Raspberry Pi 4.

The prediction page provides:

- Predicted PM2.5 / ISPU value
- Air quality category
- Prediction information
- ISPU category reference

### Device Information
Displays:

- System status
- Firebase connection status
- ESP32 information
- PMS7003
- MQ-7
- MQ-135
- DHT22
